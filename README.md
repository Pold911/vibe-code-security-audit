# vibe-code-security-audit

> A Claude Code skill that audits web apps and AI-generated code for the 20 most common and dangerous security vulnerabilities.

## Installation

Copy `skill.md` into your Claude Code skills directory:

```bash
cp skill.md ~/.claude/skills/vibe-code-security-audit.md
```

## Usage

Trigger the skill by asking Claude to review your code for security issues. Example prompts:

- "Audit my app for security vulnerabilities"
- "Is my code secure?"
- "Run a security review on this API"
- "Check for OWASP issues"
- "Harden my Express app"
